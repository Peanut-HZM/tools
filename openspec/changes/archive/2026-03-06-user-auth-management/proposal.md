# CrossShare 认证与 CRUD 功能增强

## 概述

为 CrossShare 设备传传工具添加完整的用户认证系统和资源管理功能。

## 目标

1. 实现 JWT 用户认证系统，支持注册、登录、token 管理
2. 为消息添加完整的 CRUD 功能（创建、读取、更新、删除）
3. 为文件添加完整的 CRUD 功能（创建、读取、更新、删除）
4. 确保用户只能访问和管理自己的资源
5. 提供友好的前端操作界面

## 范围

### 包含
- 用户注册和登录
- JWT token 签发和验证
- 消息编辑和删除功能
- 文件重命名和删除功能
- 用户资源隔离验证
- 前端认证 UI 和 CRUD 操作界面

### 不包含
- 第三方登录（Google、GitHub 等）
- 双因素认证
- 文件版本控制
- 消息回复和引用

## 用户故事

1. 作为新用户，我可以注册账号并开始使用 CrossShare
2. 作为已注册用户，我可以登录并访问我的数据
3. 作为用户，我可以发送、编辑和删除我的消息
4. 作为用户，我可以上传、重命名和删除我的文件
5. 作为用户，我确保只能看到和操作我自己的资源

## 验收标准

- [ ] 用户可以成功注册和登录
- [ ] 未认证用户无法访问受保护的 API
- [ ] 用户可以编辑和删除自己的消息
- [ ] 用户可以重命名和删除自己的文件
- [ ] 用户无法访问其他用户的资源
- [ ] token 过期后自动刷新或提示重新登录
