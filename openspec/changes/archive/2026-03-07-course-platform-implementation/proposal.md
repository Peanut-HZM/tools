# Proposal: 课程学习平台实现

**创建日期:** 2026-03-07
**状态:** ✅ 已完成

---

## Why

构建一个完整的课程学习平台，实现以下目标：

1. **多课程管理能力** - 从单一课程扩展到支持多门课程
2. **用户体验提升** - 提供课程浏览、筛选、评价等完整学习体验
3. **互动功能** - 点赞、收藏、评价等社交化学习功能
4. **数据驱动** - 通过统计数据了解课程热度和用户偏好
5. **内容创作工具** - 富文本编辑器和 OSS 上传支持多媒体内容

---

## What Changes

### 新增功能
- 课程列表页面和筛选功能
- 课程详情页面和报名系统
- 课程学习页面（支持多课程）
- 我的课程页面和进度追踪
- 课程评价和互动系统
- 后台多课程管理功能
- 富文本编辑器和 OSS 上传

### 数据库变更
- 新增 12 张表（7 张核心业务表 + 5 张用户交互表）
- 现有课程数据迁移到新表结构

### API 变更
- 公开 API: 课程列表、详情、分类、报名、互动、评价
- 管理 API: 课程 CRUD、章节管理、测验管理、资源管理

## 1. 问题陈述

### 1.1 当前状态

当前系统已有 OpenSpec VibeCoding 课程的单课程实现：
- ✅ 5 个章节内容已在数据库中
- ✅ 测验和资源功能已实现
- ✅ 单课程学习页面正常工作

### 1.2 存在的问题

1. **缺乏多课程管理能力**
   - 后台只能管理单一课程（OpenSpec VibeCoding）
   - 无法创建新课程
   - 无法管理课程分类和元数据

2. **缺少课程统计和互动功能**
   - 没有点赞、收藏功能
   - 没有观看次数统计
   - 没有课程评价系统

3. **缺少统一的课程学习入口**
   - 首页只有单个课程卡片
   - 没有课程列表页面
   - 用户无法浏览所有课程

4. **课程内容编辑功能不完善**
   - 缺少富文本编辑器
   - 不支持图片/视频上传到 OSS
   - 无法添加多媒体资源

## 2. 解决方案

### 2.1 核心能力

构建一个完整的课程学习平台，提供以下能力：

| 能力 | 描述 |
|------|------|
| **course-platform** | 多课程平台架构，支持创建、管理、展示多门课程 |
| **course-categorization** | 课程分类系统，支持树形分类结构 |
| **course-interactions** | 用户互动功能：点赞、收藏、评价 |
| **course-progress-tracking** | 学习进度追踪，支持多课程 |
| **course-statistics** | 课程统计数据：浏览量、点赞数、完成数等 |
| **rich-content-editor** | 富文本编辑器，支持 Markdown 和 OSS 上传 |

### 2.2 架构设计

采用完整平台化架构，包含 12 张数据库表：

```
核心业务表 (7 张):
- courses (课程主表)
- course_categories (课程分类)
- course_chapters (课程章节)
- course_quizzes (课程测验)
- course_quiz_questions (测验题目)
- course_quiz_options (测验选项)
- course_resources (课程资源)

用户交互表 (5 张):
- course_enrollments (用户课程关联)
- course_progress (学习进度)
- course_interactions (课程互动)
- course_reviews (课程评价)
- course_statistics (课程统计)
```

### 2.3 数据迁移

现有 OpenSpec VibeCoding 课程内容将通过迁移脚本完整迁移到新表结构：
1. 导出当前 5 个章节、测验、资源数据
2. 导入到新创建的表中
3. 初始化统计数据
4. 验证数据完整性
