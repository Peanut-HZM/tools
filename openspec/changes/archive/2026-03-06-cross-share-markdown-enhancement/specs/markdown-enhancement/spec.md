### Requirement: 智能内容识别

系统应自动识别用户发送的内容类型，并进行相应处理。

#### 检测规则

| 类型 | 检测规则 | 优先级 |
|------|----------|--------|
| JSON | 内容以 `{` 或 `[` 开头，且能被 `JSON.parse()` 解析 | 1 |
| 代码块 | 内容以 ``` 开头，后跟可选语言标识 | 2 |
| Markdown | 包含 Markdown 语法特征（`#`, `*`, `-`, `` ` ``, `>` 等） | 3 |
| 普通文本 | 不满足以上任何条件 | 4 |

#### 处理逻辑

```
用户发送内容
    ↓
detectContentType(content): ContentType
    ├── 'json' → 使用 JsonViewer 组件
    ├── 'code' → 使用 CodeViewer 组件
    ├── 'markdown' → 使用 ReactMarkdown 渲染
    └── 'text' → 段落格式化显示
```

#### 验收标准

- [ ] JSON 内容能被正确识别并格式化
- [ ] 无效 JSON 不被误判为 JSON 类型
- [ ] 代码块能识别常见语言（javascript, typescript, python, java, go, bash 等）
- [ ] 普通文本正常显示

### Requirement: 混合模式展示

长内容应默认折叠，避免占用过多屏幕空间。

#### 行数计算

- JSON/代码：按实际行数计算
- Markdown：按渲染后的行数计算

#### 折叠阈值

| 内容类型 | 阈值 | 折叠时显示 |
|----------|------|------------|
| JSON | >10 行 | 显示前 10 行 + "展开查看详情（共 X 行）" |
| 代码 | >10 行 | 显示前 10 行 + "展开查看详情（共 X 行）" |
| Markdown | >10 行 | 显示前 10 行 + "展开查看详情" |

#### 展开/折叠交互

- 点击"展开"按钮 → 完全展开内容
- 点击"折叠"按钮 → 恢复折叠状态
- 动画过渡：200ms ease-in-out

#### 验收标准

- [ ] ≤10 行内容直接展开显示
- [ ] >10 行内容默认折叠
- [ ] 点击展开/折叠按钮无延迟
- [ ] 折叠状态保存（重新进入页面后恢复折叠）

### Requirement: 语法高亮

JSON 和代码块应使用专业语法高亮。

#### 主题选择

- **深色主题**：`vs2015` 或 `atom-one-dark`
- **行号**：显示行号
- **自动检测语言**：支持 javascript, typescript, python, java, go, bash, json 等

#### JSON 格式化

```typescript
// 示例
{
  "key": "value",
  "nested": {
    "array": [1, 2, 3]
  }
}
```

#### 代码块格式化

````typescript
// 示例
function hello() {
  console.log("Hello, World!");
}
````

#### 验收标准

- [ ] JSON 缩进正确（2 空格）
- [ ] 代码高亮颜色正确区分关键字、字符串、注释等
- [ ] 支持行号显示
- [ ] 高亮主题与系统深色主题协调

### Requirement: 多种复制方式

每条消息应提供多种复制选项。

#### 复制选项

| 选项 | 说明 | 输出格式 |
|------|------|----------|
| 复制内容 | 复制纯文本内容 | `msg.content` |
| 复制 Markdown 源码 | 复制原始 Markdown | `msg.content`（原始） |
| 复制渲染 HTML | 复制渲染后的 HTML | `<div class="markdown-body">...</div>` |

#### 交互设计

```
[更多操作 ▼]
├── 复制内容
├── 复制 Markdown 源码
└── 复制渲染 HTML
```

#### 反馈机制

- 复制成功：Toast 提示 "已复制到剪贴板"
- 复制失败：Toast 提示 "复制失败，请手动复制"

#### 验收标准

- [ ] 点击复制选项后内容正确写入剪贴板
- [ ] 复制成功显示 Toast 提示
- [ ] 复制失败有错误提示
- [ ] 下拉菜单在消息 hover 时显示

### Requirement: Markdown 增强编辑

编辑消息时应提供实时预览和快捷工具。

#### 编辑器布局

```
┌─────────────────────────────────────────────┐
│ [B] [I] [Link] [Code] [List] [Quote]       │ ← 工具栏
├─────────────────────┬───────────────────────┤
│                     │                       │
│   编辑区            │    预览区              │ ← 左右分栏
│   (textarea)        │   (ReactMarkdown)     │
│                     │                       │
├─────────────────────┴───────────────────────┤
│            [保存] [取消]                     │ ← 操作按钮
└─────────────────────────────────────────────┘
```

#### 工具栏功能

| 按钮 | 插入内容 | 快捷键 |
|------|----------|--------|
| **B** | `**选中文本**` | Ctrl+B |
| *I* | `*选中文本*` | Ctrl+I |
| Link | `[文本](url)` | Ctrl+K |
| Code | `` `选中文本` `` | Ctrl+E |
| List | `- 列表项` | Ctrl+L |
| Quote | `> 引用` | Ctrl+Q |

#### 分栏调整

- 支持拖拽中间分隔线调整左右比例
- 默认比例：50% / 50%
- 响应式：窄屏时自动切换为上下布局

#### 验收标准

- [ ] 工具栏按钮正确插入 Markdown 语法
- [ ] 快捷键正常工作
- [ ] 预览区实时更新
- [ ] 支持拖拽调整分栏比例
- [ ] 窄屏自动切换布局
