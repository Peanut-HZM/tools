## Why

目前 OpenSpec VibeCoding 课程的章节、测验、资源等内容数据是硬编码或通过数据库手动管理，缺乏一个统一的后台管理界面。管理员无法方便地进行课程内容的增删查改操作，需要直接操作数据库或 API，效率低下且容易出错。

## What Changes

- **新增课程章节管理页面**：在后台管理系统中添加课程章节管理模块，支持章节的增删查改
- **新增测验管理功能**：支持在后台创建、编辑、删除测验，包括题目和选项的管理
- **新增资源管理功能**：支持为章节添加、编辑、删除学习资源（代码示例、对比材料、视频、模板等）
- **新增课程排序功能**：支持调整章节顺序，支持锁定/解锁章节控制学习顺序
- **前端课程展示对接后台数据**：前端课程页面完全基于后台配置的数据进行展示

## Capabilities

### New Capabilities

- `course-admin`: 后台课程管理功能，包括章节、测验、资源的增删查改界面和 API
- `course-data-model`: 课程数据模型和数据库表的完善，支持更丰富的课程内容管理

### Modified Capabilities

- `openspec-course`: 前端课程展示页面需要对接新的后台管理 API，支持动态加载配置数据

## Impact

- **后端 API**：需要新增和完善课程管理相关的 CRUD API
- **前端页面**：需要新增后台课程管理页面，前端课程展示页面需要适配新的数据结构
- **数据库**：可能需要扩展现有的课程相关表结构
- **现有功能**：不影响现有的课程学习功能，只是数据源从硬编码变为后台配置
