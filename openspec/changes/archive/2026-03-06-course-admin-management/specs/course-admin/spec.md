## ADDED Requirements

### Requirement: 管理员可以管理课程章节

管理员可以在后台管理系统中对课程章节进行增删查改操作，包括章节标题、内容、类型、排序、锁定状态等。

#### Scenario: 创建新章节
- **WHEN** 管理员点击"新增章节"按钮，填写章节信息（标题、标识符、内容、类型等）并保存
- **THEN** 系统创建新章节，章节列表中显示新章节，支持后续编辑

#### Scenario: 编辑章节
- **WHEN** 管理员在章节列表中点击某个章节的"编辑"按钮，修改章节信息后保存
- **THEN** 系统更新章节信息，保留章节 ID 和创建时间

#### Scenario: 删除章节
- **WHEN** 管理员点击章节的"删除"按钮并确认
- **THEN** 系统删除该章节，同时删除关联的测验和资源

#### Scenario: 调整章节顺序
- **WHEN** 管理员通过拖拽或输入序号调整章节顺序
- **THEN** 系统更新章节的 order 字段，列表按新顺序展示

#### Scenario: 锁定/解锁章节
- **WHEN** 管理员切换章节的锁定状态
- **THEN** 系统更新 is_locked 字段，前端学习页面根据锁定状态控制访问

#### Scenario: 查看章节列表
- **WHEN** 管理员进入课程管理页面
- **THEN** 系统按 order 字段升序展示所有章节，显示标题、类型、锁定状态、创建时间

### Requirement: 管理员可以管理测验

管理员可以在后台为章节创建、编辑、删除测验，包括题目和选项的管理。

#### Scenario: 为章节创建测验
- **WHEN** 管理员在章节管理中选择"添加测验"，填写测验标题、及格分数，并添加题目
- **THEN** 系统创建测验，关联到对应章节

#### Scenario: 添加测验题目
- **WHEN** 管理员在测验编辑页面点击"添加题目"，填写题目内容、类型、正确答案、解析，并添加选项
- **THEN** 系统创建题目及其选项，关联到对应测验

#### Scenario: 编辑测验题目
- **WHEN** 管理员展开某个题目，修改题目内容或选项后保存
- **THEN** 系统更新题目及其选项信息

#### Scenario: 删除测验题目
- **WHEN** 管理员点击题目的"删除"按钮并确认
- **THEN** 系统删除该题目及其所有选项

#### Scenario: 调整题目顺序
- **WHEN** 管理员通过拖拽调整题目顺序
- **THEN** 系统更新题目的 order 字段

#### Scenario: 删除测验
- **WHEN** 管理员点击测验的"删除"按钮并确认
- **THEN** 系统删除测验及其所有题目和选项

### Requirement: 管理员可以管理课程资源

管理员可以在后台为章节添加、编辑、删除学习资源，支持代码示例、对比材料、视频、模板等类型。

#### Scenario: 添加章节资源
- **WHEN** 管理员在章节管理中选择"添加资源"，填写资源标题、类型、内容
- **THEN** 系统创建资源，关联到对应章节

#### Scenario: 编辑资源
- **WHEN** 管理员点击资源的"编辑"按钮，修改资源信息后保存
- **THEN** 系统更新资源信息

#### Scenario: 删除资源
- **WHEN** 管理员点击资源的"删除"按钮并确认
- **THEN** 系统删除该资源

#### Scenario: 查看章节资源列表
- **WHEN** 管理员在章节详情中查看资源列表
- **THEN** 系统展示该章节的所有资源，显示标题、类型、创建时间

### Requirement: 系统提供 Markdown 编辑器

章节内容和资源内容使用 Markdown 格式，系统提供实时预览的编辑器。

#### Scenario: 编辑章节内容
- **WHEN** 管理员在章节编辑页面使用 Markdown 编辑器输入内容
- **THEN** 系统支持 Markdown 语法高亮，可切换预览模式查看渲染效果

#### Scenario: 复制代码块
- **WHEN** 管理员在预览模式下点击代码块的"复制"按钮
- **THEN** 系统将代码内容复制到剪贴板

### Requirement: 系统验证数据完整性

在创建和更新章节、测验、资源时，系统进行必要的验证。

#### Scenario: 验证章节标识符唯一性
- **WHEN** 管理员创建章节时输入已存在的 slug
- **THEN** 系统提示"标识符已存在"，阻止保存

#### Scenario: 验证必填字段
- **WHEN** 管理员提交表单时留空必填字段（如标题、内容）
- **THEN** 系统高亮显示缺失字段，提示"此字段为必填项"

#### Scenario: 验证测验正确答案
- **WHEN** 管理员设置题目正确答案时选择无效选项
- **THEN** 系统验证答案有效性，阻止保存
