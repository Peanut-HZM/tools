## ADDED Requirements

### Requirement: API Key 支持分类
系统 SHALL 为每个 API Key 配置提供分类功能，支持"对话类型"和"编程类型"两种分类。

#### Scenario: 选择分类
- **WHEN** 用户在新增/编辑配置时
- **THEN** 系统提供分类下拉选择器，包含"对话类型"和"编程类型"选项

#### Scenario: 对话类型
- **WHEN** 用户选择"对话类型"
- **THEN** 该配置用于聊天、问答等对话场景

#### Scenario: 编程类型
- **WHEN** 用户选择"编程类型"
- **THEN** 该配置用于代码生成、代码补全等编程场景

### Requirement: 按分类筛选配置
系统 SHALL 允许用户按分类筛选配置列表。

#### Scenario: 筛选对话类型
- **WHEN** 用户点击"对话类型"筛选标签
- **THEN** 列表只显示分类为"对话类型"的配置

#### Scenario: 筛选编程类型
- **WHEN** 用户点击"编程类型"筛选标签
- **THEN** 列表只显示分类为"编程类型"的配置

#### Scenario: 显示全部
- **WHEN** 用户点击"全部"筛选标签
- **THEN** 列表显示所有配置，不限分类

### Requirement: 分类字段显示
系统 SHALL 在配置列表中清晰显示每个配置的分类。

#### Scenario: 查看分类标签
- **WHEN** 用户查看配置列表
- **THEN** 每个配置行显示对应的分类标签（对话类型/编程类型），使用不同颜色区分
