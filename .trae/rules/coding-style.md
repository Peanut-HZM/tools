# 代码规范

1. 生成代码时必须添加类级和函数级注释,所有代码作者为huazhongmin
2. 使用import导包，禁止使用全限定名称引用类
3. 禁止使用枚举类型作为entity、request、response、dto对象的字段类型，禁止以枚举类作为方法的入参，确保接口的通用性和可扩展性
4. 新增数据的id使用已存在的雪花算法生成器生成
5. 所有代码必须符合Java编码规范，包括命名规范、注释规范、代码格式等
6. 所有类的使用应该现在类的定义之前使用import导入，避免在代码中直接使用全限定名称引用类
7. 避免在循环中进行数据库操作，如在for循环中执行批量插入操作，应使用批量插入方法
8. 避免在循环中调用http,feign等接口，如在for循环中调用用户服务接口获取用户信息，应使用批量查询方法获取所有用户信息后再进行处理
9. 调用feign接口时必须确保在对应的微服务中存在对应的接口,若不存在则需要先定义接口,并在微服务中实现该接口
