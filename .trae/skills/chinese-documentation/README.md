# 中文文档编写规范技能

## 概述

这个技能确保在创建新的 Markdown 文档时，优先使用中文命名和内容，只有在必须使用英文的地方（如代码、命令、技术术语）才使用英文。

## 使用场景

- 创建新的 Markdown 文档
- 编写项目文档
- 编写技术文档
- 编写用户指南
- 编写 API 文档

## 核心原则

1. **文档名称**：优先使用中文或拼音
2. **文档内容**：优先使用中文
3. **代码示例**：代码本身保持英文，注释可以使用中文
4. **技术术语**：保持英文，但加中文解释
5. **命令和路径**：保持英文，但说明使用中文

## 文件位置

- 技能文件：`.cursor/skills/chinese-documentation/chinese-documentation.mdc`
- 说明文档：`.cursor/skills/chinese-documentation/README.md`
