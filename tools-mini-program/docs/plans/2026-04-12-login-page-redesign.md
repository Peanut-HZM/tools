# 小程序登录页面重新设计

## 概述

将工具箱小程序的登录/注册页面从基础样式升级为专业 Dark Mode 设计。

## 设计原则

- **Dark Mode (OLED) 优化**：深色背景 + 高对比度文字
- **Swiss Modernism 简洁布局**：清晰层次 + 数学化间距
- **无障碍优先**：所有交互元素符合 WCAG AA 标准

## 配色方案

| 角色 | 颜色值 | 用途 |
|------|--------|------|
| 背景主色 | #0F172A | 页面背景 |
| 卡片背景 | #1E293B | 表单容器 |
| 主色调 | #3B82F6 | 按钮、链接、聚焦态 |
| 成功色 | #10B981 | 成功提示 |
| 错误色 | #EF4444 | 错误提示 |
| 文字主色 | #F8FAFC | 主要文字 |
| 文字次色 | #94A3B8 | 次要文字 |
| 占位文字 | #64748B | Placeholder |
| 边框 | #334155 | 输入框边框 |

## 修改文件

- `src/pages/login/index.tsx` — 添加 Tab 切换器、SVG 图标、输入框图标
- `src/pages/login/index.scss` — 完全重写样式

## 关键改进

1. ~~SVG 工具箱图标~~ → Unicode 字符图标（⚙）替代 Emoji（SVG 在小程序中不支持）
2. Tab 切换器替代文字链接
3. 输入框前缀图标（👤 用户、🔒 锁、✉ 邮箱）
4. 聚焦态蓝色光晕效果
5. 错误提示左侧红色竖条 + ⚠ 警告图标
6. 渐变按钮背景
7. 背景装饰性光晕效果

## 兼容性说明

- **SVG 不支持**: 微信小程序不支持原生 `<svg>` 标签，已替换为 Unicode 字符 + CSS 样式
- **Emoji 使用策略**: 输入框前缀使用系统 emoji（👤🔒✉），Logo 和警告图标使用 Unicode 符号（⚙⚠），确保跨平台一致性
- **focus-within**: 小程序支持 `:focus-within` 伪类，输入框聚焦光晕效果可用
