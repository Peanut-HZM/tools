# 产品经理 Agent Prompt 原型设计文档

## 1. 产品概述

### 1.1 设计目标
为产品经理 Agent 创建一个专业、直观、高效的对话界面，帮助用户轻松完成从想法到完整 PRD 的转化过程。

### 1.2 设计原则
- **简洁性**：界面清晰，减少认知负担
- **引导性**：通过视觉引导帮助用户完成流程
- **专业性**：体现产品经理的专业特质
- **反馈性**：实时展示处理进度和结果

## 5. 交互流程设计

### 5.1 核心交互流程

#### 5.1.1 首次使用引导

```
用户打开页面
    ↓
显示欢迎界面 + 功能介绍
    ↓
提供三种启动方式：
  ├─ [一句话描述想法]
  ├─ [上传现有文档]
  └─ [查看示例]
    ↓
进入对话界面，开始需求澄清
```

#### 5.1.2 标准对话流程

```
用户输入需求
    ↓
Agent 分析输入类型
    ↓
判断当前阶段
    ↓
┌──────────┬──────────┬──────────┐
│ 需求理解  │ 市场研究  │ 文档生成  │
└────┬─────┴────┬─────┴────┬─────┘
     │          │          │
显示分析进度    自动搜索竞品   整合所有信息
     │          │          │
提出澄清问题   生成对比表格   生成完整PRD
     │          │          │
等待用户回答   等待用户确认   等待用户反馈
     │          │          │
     └──────────┴──────────┘
              ↓
        用户确认/修改
              ↓
        进入下一阶段/重新生成
```

### 5.2 关键交互细节

#### 5.2.1 消息发送

| 操作 | 反馈 |
|------|------|
| 输入文字 | 实时显示输入状态 |
| 按 Enter | 发送消息，显示发送中状态 |
| 上传文件 | 显示进度条，完成后显示文件卡片 |
| @Agent | 触发快捷命令菜单 |

#### 5.2.2 快捷操作

```
用户输入：@
    ↓
弹出快捷命令菜单
    ↓
┌────────────────────────────────────┐
│ @分析竞品    @生成流程图  @查看PRD │
│ @优化需求    @添加功能    @导文档  │
└────────────────────────────────────┘
    ↓
选择命令，自动填充到输入框
```

#### 5.2.3 PRD 预览与编辑

```
PRD 生成完成
    ↓
显示 PRD 预览卡片
    ↓
提供操作选项：
  ├─ [在线编辑] → 打开富文本编辑器
  ├─ [查看完整] → 展开全部内容
  ├─ [局部修改] → 选择章节修改
  ├─ [导出] → PDF / Markdown / Word
  └─ [分享] → 生成分享链接
```

## 10. 响应式设计

### 10.1 Desktop（≥1280px）

- 完整三栏布局
- 侧边栏固定显示
- 消息气泡最大宽度 70%
- 工具栏平铺显示

### 10.2 Tablet（768px - 1279px）

- 主内容区全宽
- 侧边栏可滑动呼出
- 消息气泡最大宽度 85%
- 工具栏收起为图标

### 10.3 Mobile（<768px）

- 单栏布局
- 底部导航栏
- 消息气泡全宽
- 输入框固定在底部
- 侧边栏变为抽屉式

/* Mobile 适配 */
@media (max-width: 767px) {
  .sidebar {
    position: fixed;
    left: -100%;

  }
  
  .sidebar.open {
    left: 0;
  }
  
  .message-bubble {

  }
  
  .input-area {
    position: fixed;

## 11. 可访问性设计

### 11.1 键盘导航

| 快捷键 | 功能 |
|--------|------|
| Tab | 在可聚焦元素间切换 |
| Shift+Tab | 反向切换 |
| Enter | 激活按钮或发送消息 |
| Escape | 关闭模态框或菜单 |
| Ctrl+N | 新建对话 |
| Ctrl+F | 搜索会话 |
| Ctrl+Enter | 发送消息 |
| Ctrl+/ | 显示快捷键帮助 |

### 11.2 屏幕阅读器支持

- 所有图标都有 aria-label
- 消息区域使用 role="log" aria-live="polite"
- 加载状态使用 role="status"
- 阶段指示器使用 aria-current="step"

### 11.3 对比度

- 正文文字与背景对比度 ≥ 4.5:1
- 大文字（18px+）对比度 ≥ 3:1
- 焦点状态清晰可见
