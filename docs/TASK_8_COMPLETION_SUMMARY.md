#### 新增功能
1. **质量选择器**
   - 位置：视频列表顶部
   - 6种质量选项：最佳、1080p、720p、480p、360p、最低
   - 全局设置，应用于所有下载

2. **服务器下载按钮**
   - HLS视频：绿色"服务器下载 (支持HLS)"
   - 普通视频：蓝色"直接下载" + 绿色"服务器下载"

3. **实时进度显示**
   - 任务状态：等待中、下载中、完成、失败
   - 进度条（绿色，动画过渡）
   - 进度百分比（精确到0.1%）
   - 下载速度（如：2.5MB/s）
   - 预计剩余时间（如：30s）
   - 取消按钮（下载中可用）

4. **自动下载功能**
   - 任务完成后自动触发文件下载
   - 使用 Blob 方式确保文件完整性
   - 自动设置文件名
   - 3秒后清理任务状态

5. **取消下载功能**
   - 下载中可以随时取消
   - 调用后端取消API
   - 清理前端状态

## 🎯 核心功能

### 下载流程
```
用户点击"服务器下载" 
  ↓
创建下载任务（POST /api/tools/download-video-ytdlp）
  ↓
获取任务ID
  ↓
开始轮询状态（每秒查询一次）
  ↓
更新进度条、速度、ETA
  ↓
任务完成
  ↓
自动下载文件（Blob方式）
  ↓
3秒后清理状态
```

### 支持的视频类型
1. **HLS流媒体** (.m3u8, .ts)
   - 自动处理
   - 使用 yt-dlp + ffmpeg
   - 合并为完整MP4

2. **YouTube/Vimeo等平台**
   - 支持1000+网站
   - 自动提取视频
   - 质量选择

3. **普通视频** (MP4, WebM, OGG)
   - 两种下载方式
   - 直接下载或服务器下载

### 场景1: 下载YouTube视频
```

5. 点击"服务器下载 (支持HLS)"
6. 等待下载完成
7. 获得完整的MP4文件
```
