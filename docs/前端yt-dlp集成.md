# yt-dlp 集成测试指南

## 🎯 测试目标

验证 yt-dlp 服务器下载功能在前端和后端的完整集成。

## 🚀 快速开始

### 前置条件
- ✅ 后端运行在 http://localhost:8000
- ✅ 前端运行在 http://localhost:3000
- ✅ yt-dlp 和 imageio-ffmpeg 已安装

### 访问测试页面
1. 打开浏览器访问: http://localhost:3000
2. 点击"网页视频下载"工具卡片
3. 进入视频下载器页面

## 📋 测试用例

### 测试1: 质量选择器
**目的**: 验证质量选择器正常工作

**步骤**:
1. 在视频列表顶部找到"下载质量"选择器
2. 点击下拉菜单
3. 验证显示6个选项：最佳质量、1080p、720p、480p、360p、最低质量
4. 选择不同的质量选项

**预期结果**:
- ✅ 选择器正常显示
- ✅ 可以切换不同质量
- ✅ 选中的质量会应用到后续下载

### 测试2: YouTube视频下载

**测试URL**: `https://www.youtube.com/watch?v=jNQXAC9IVRw`

- ✅ 进度达到100%
- ✅ 显示"✅ 完成"

## 🔍 API 测试

### 测试API端点

#### 1. 创建下载任务
```bash
curl -X POST http://localhost:8000/api/tools/download-video-ytdlp \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.youtube.com/watch?v=jNQXAC9IVRw",
    "quality": "worst"
  }'
```

**预期响应**:
```json
{
  "task_id": "uuid-here",
  "status": "pending",
  "message": "下载任务已创建，正在排队中..."
}
```

#### 2. 查询任务状态
```bash
curl http://localhost:8000/api/tools/download-task/{task_id}
```

**预期响应**:
```json
{
  "task_id": "uuid-here",
  "status": "downloading",
  "progress": 45.5,
  "file_size": "10.5MB",
  "speed": "2.5MB/s",
  "eta": "30s",
  "error": null
}
```

#### 3. 下载文件
```bash
curl -O http://localhost:8000/api/tools/download-file/{task_id}
```

**预期结果**:
- ✅ 文件开始下载
- ✅ 文件名正确
- ✅ 文件可以正常播放

#### 4. 获取统计信息
```bash
curl http://localhost:8000/api/tools/download-stats
```

**预期响应**:
```json
{
  "total_tasks": 5,
  "pending": 0,
  "downloading": 2,
  "completed": 3,
  "failed": 0,
  "success_rate": 100.0
}
```

#### 5. 取消任务
```bash
curl -X DELETE http://localhost:8000/api/tools/download-task/{task_id}
```

**预期响应**:
```json
{
  "message": "任务已取消"
}
```

## 🐛 已知问题

### 问题1: 某些网站需要登录
**现象**: 提示"需要登录"
**解决**: 使用浏览器开发者工具获取实际视频URL

### 问题2: 地区限制
**现象**: 提示"该视频在您的地区不可用"
**解决**: 使用VPN或选择其他视频

### 问题3: 下载速度慢
**现象**: 下载速度很慢
**原因**: 
- 视频源服务器限速
- 网络连接慢
**解决**: 选择较低质量
