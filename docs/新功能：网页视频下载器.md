# 新功能：网页视频下载器

## ✨ 功能概述

已成功添加"网页视频下载器"工具，允许用户粘贴网页URL，自动提取并下载该网页的视频资源。

## 🎯 功能特性

### 核心功能
- ✅ 输入任意网页URL
- ✅ 自动提取网页中的所有视频资源
- ✅ 支持多种视频格式（MP4、WebM、OGG、M3U8、MPD等）
- ✅ 支持多种提取方式（video标签、source标签、iframe、脚本）
- ✅ 识别嵌入视频（YouTube、Vimeo、Bilibili等）
- ✅ 显示视频来源和类型标签
- ✅ 复制视频链接到剪贴板
- ✅ 在新窗口打开视频
- ✅ 友好的错误处理和使用说明

### 技术实现
- **后端**: Python + BeautifulSoup4 + Requests + 正则表达式
- **前端**: React + TypeScript
- **视频提取**: 多种策略组合提取
  - HTML标签解析（video、source）
  - iframe嵌入视频识别
  - JavaScript脚本中的视频URL提取
- **URL处理**: 自动转换相对路径为绝对路径
- **去重**: 自动过滤重复视频

## 🚀 使用方法

### 1. 访问工具
1. 打开 http://localhost:3000
2. 在首页找到"网页视频下载"工具卡片（紫色图标）
3. 点击卡片进入工具页面

### 2. 提取视频
1. 在输入框中粘贴完整的网页URL
   - 例如：https://example.com
2. 点击"提取视频"按钮或按Enter键
3. 等待系统提取视频（通常几秒钟）

### 3. 使用视频
- **复制链接**: 点击"复制链接"按钮，复制到剪贴板
- **在新窗口打开**: 直接在浏览器中打开视频
- **观看视频**: 对于嵌入视频（如YouTube），点击观看

### 4. 下载视频
- **直接下载**: 对于MP4等标准格式，右键保存
- **使用工具**: 使用IDM、you-get、youtube-dl等专业工具
- **M3U8格式**: 使用FFmpeg或专门的M3U8下载工具

## 💡 使用提示

1. **URL格式**: 必须包含 http:// 或 https://
2. **视频格式**: 支持MP4、WebM、OGG、M3U8、MPD等
3. **嵌入视频**: YouTube等平台需要专门的下载工具
4. **M3U8流**: 需要使用FFmpeg等工具转换
5. **版权注意**: 请尊重视频版权，仅用于合法用途

## 🔧 技术细节

### 后端API

#### 端点
```
POST /api/tools/extract-videos
```

#### 请求体
```json
{
  "url": "https://example.com"
}
```

#### 响应
```json
{
  "videos": [
    {
      "url": "https://example.com/video.mp4",
      "type": "video/mp4",
      "source": "video",
      "index": 0
    }
  ],
  "count": 1
}
```

## 🔍 工作原理

### 视频提取流程

1. **接收URL**: 用户输入网页URL
2. **发送请求**: 后端使用requests获取网页HTML
3. **解析HTML**: BeautifulSoup4解析HTML结构
4. **多策略提取**:
   - 提取`<video>`标签的src属性
   - 提取`<source>`标签的src属性
   - 识别`<iframe>`嵌入视频
   - 使用正则表达式从JavaScript中提取视频URL
5. **URL规范化**: 转换相对路径为绝对路径
6. **过滤去重**: 移除重复和无效视频
7. **返回结果**: 返回视频列表给前端
8. **显示列表**: 前端展示视频信息
9. **提供操作**: 用户可复制链接或打开视频

### 智能特性

- **多属性支持**: 支持 src、data-src 等属性
- **URL规范化**: 自动处理相对路径和绝对路径
- **平台识别**: 识别YouTube、Vimeo、Bilibili等平台
- **格式检测**: 自动识别视频格式和MIME类型
- **脚本提取**: 从JavaScript代码中提取视频URL
- **去重优化**: 基于URL去重

## 🛠️ 推荐下载工具

### 通用下载工具
- **IDM (Internet Download Manager)** - Windows平台强大的下载工具
- **Free Download Manager** - 跨平台免费下载工具
- **Aria2** - 命令行下载工具

### 视频专用工具
- **youtube-dl** - 支持1000+网站的视频下载工具
- **you-get** - Python编写的视频下载工具
- **yt-dlp** - youtube-dl的增强版
- **FFmpeg** - 视频处理和转换工具

### 使用示例

#### youtube-dl
```bash
youtube-dl [视频URL]
```

#### you-get
```bash
you-get [视频URL]
```

#### FFmpeg (M3U8)
```bash
ffmpeg -i [M3U8_URL] -c copy output.mp4
```
