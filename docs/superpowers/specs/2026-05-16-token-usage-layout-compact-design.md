# Token Usage 操作行精简设计

## 目标

优化 `http://localhost:5178/tools/token-usage` 页面顶部操作行（DataFreshnessBadge + 按钮组），压缩高度从 ~60px 到 ~32px，确保单行不换行。

## 方案：全部精简

### 1. DataFreshnessBadge 精简

**当前：** 带边框卡片，3 行内容（状态标签、最后同步时间、缓存有效期+原因+错误），`min-w-[300px]`

**改为：** 内联一行文本，仅显示最后同步时间，其余信息放入 Tooltip（悬停显示）

```
当前：
┌────────────────────────────────────┐
│ 🕐 缓存有效               [刷新]   │
│ 最后同步：2分钟前 2026-05-16...    │
│ 缓存有效期：剩余 58 分钟           │
└────────────────────────────────────┘

改为：
🕐 最后同步 2 分钟前
    ↑ hover 显示 Tooltip：缓存有效期、stale 原因、刷新锁状态、错误信息
```

- 移除边框卡片样式，改为内联 `span` + 图标
- 状态异常（stale/error）时改变图标颜色和文字颜色
- 详细信息通过 `title` 属性或 Tooltip 组件展示

### 2. 按钮精简

**当前：** 带文字的标准按钮 `[🔄 刷新]` `[📥 导出]` `[🗑 清理]`

**改为：** 纯图标按钮 + Tooltip 提示

```
[🔄] [📥] [🗑]
 ↑   ↑   ↑
 tooltip: "刷新" / "导出" / "清理"
```

- 移除按钮内文字，改为纯图标
- 使用 `title` 属性展示操作提示
- 保持原有尺寸 36x36px（`h-9 w-9`）

### 3. 整行布局

```
🕐 最后同步 2 分钟前          [🔄] [📥] [🗑]
```

- 左侧：状态文本（`flex-1`，超出省略号截断）
- 右侧：图标按钮组（`flex-shrink-0`）
- `flex-nowrap` 确保永不换行
- 整行高度 ~32px

### 4. UI 状态变化

| 场景 | 图标 | 文字 | Tooltip |
|------|------|------|---------|
| 缓存有效 | 🕐 (green) | "最后同步 2 分钟前" | 缓存 TTL、缓存时间 |
| 数据过期 | ⚠️ (amber) | "数据已过期" | stale_reason |
| 刷新中 | 🔄 (spinning) | "后台更新中" | — |
| 刷新失败 | ⚠️ (amber) | "刷新失败" | 错误详情 |
| 锁状态 | — | — | "其他窗口正在更新" |
| 无缓存 | 🕐 (neutral) | "数据库聚合" | — |

## 涉及文件

- `frontend/src/components/Tools/TokenUsage.tsx` — 修改 `DataFreshnessBadge` 组件和按钮组

## 验收标准

- 操作行在所有窗口宽度下不换行
- 行高不超过 36px
- Tooltip 包含所有原有信息
- 异常状态颜色正确区分
