# 工具页多标签工作区设计文档

**日期**: 2026-08-11  
**状态**: 待实现  
**优先级**: 中

---

## 1. 需求背景

当前工具页采用单页导航模式：点击工具卡片后，通过路由跳转到 `/tools/{toolId}`，当前页面被完全替换。用户无法同时打开多个工具，也无法在不同工具之间快速切换。每次切换工具都需要重新加载，之前工具的状态（表单数据、连接配置、查询结果等）全部丢失。

**核心痛点**：
- 无法同时查看多个工具的输出
- 切换工具时状态丢失，需要重复操作
- 无法在工具之间快速对比数据

---

## 2. 设计目标

引入类似浏览器/VS Code 的多标签工作区模式：

1. **多标签并行**：同时打开多个工具，每个工具一个标签
2. **状态保持**：切换标签时，组件状态完全保留，不重置
3. **快速切换**：通过标签栏在工具间瞬间切换
4. **沉浸体验**：工作区模式下隐藏 Header，最大化工作空间

```

  ▼
工作区（新建标签）
  │

  ▼

  │
  │ 再次点击工具
  ▼
工作区（复用已有标签 / 新建标签）
```

## 5. 交互流程

### 5.1 从首页打开工具

```
用户点击工具卡片
  → 导航到 /workspace
  → 检查工作区是否已有该工具标签
    → 有：切换到该标签
    → 无：新建标签并激活
```

### 5.2 从左侧列表打开工具

```
用户点击左侧工具
  → 检查工作区是否已有该工具标签
    → 有：切换到该标签
    → 无：新建标签并激活
```

### 5.3 关闭标签

```
用户点击标签 ×
  → 移除标签
  → 如果关闭的是活跃标签：
    → 有剩余标签：切换到最近一个
    → 无剩余标签：显示欢迎页面
```

### 5.4 返回首页

```
用户点击"返回首页"
  → 导航到 /
  → 工作区标签状态保留在内存中
  → 再次进入工作区时恢复标签
```

## 6. 状态管理

### 6.1 工作区 Store（Zustand）

```typescript
interface WorkspaceStore {
  // 标签列表
  tabs: Tab[];
  // 当前活跃标签 ID
  activeTabId: string | null;
  
  // Actions
  addTab: (tool: Tool) => void;
  removeTab: (tabId: string) => void;
  setActiveTab: (tabId: string) => void;
}

interface Tab {
  id: string;
  toolId: string;      // 工具标识
  toolName: string;    // 显示名称
  toolIcon: string;    // 图标
  openedAt: number;    // 打开时间戳
}
```

### 6.2 状态保持方案

**方案**：所有标签组件保持挂载，用 `display: none` 隐藏非活跃标签。

```tsx
{tabs.map(tab => (
  <div
    key={tab.id}
    style={{ display: tab.id === activeTabId ? 'block' : 'none' }}
  >
    <ToolComponent toolId={tab.toolId} />
  </div>
))}
```

**优点**：
- React 组件不会卸载，状态完全保留
- 切换标签瞬间完成（无需重新渲染）
- 实现简单，无需额外的状态持久化

**缺点**：
- 内存占用随标签数增长
- 打开 10+ 标签时可能影响性能

**缓解措施**：
- 对于资源密集型工具（如 K8s 控制台），可以在组件内部实现懒加载
- 后续可考虑 LRU 缓存策略（超出阈值时卸载最久未使用的标签）

### 6.3 持久化

标签列表持久化到 `localStorage`，刷新页面后恢复：

```typescript
// Store 初始化时从 localStorage 读取
const stored = localStorage.getItem('workspace-tabs');
if (stored) {
  const { tabs, activeTabId } = JSON.parse(stored);
  // 恢复标签状态
}

// 每次标签变化时写入 localStorage
useEffect(() => {
  localStorage.setItem('workspace-tabs', JSON.stringify({ tabs, activeTabId }));
}, [tabs, activeTabId]);
```

**注意**：只持久化标签元数据（toolId、toolName 等），不持久化工具内部状态。工具内部状态由 React 组件自身管理。刷新页面后标签恢复，但工具内部状态会重置。

function LegacyToolRedirect() {
  const { toolId } = useParams();
  const navigate = useNavigate();
  const { addTab } = useWorkspaceStore();
  
  useEffect(() => {
    // 找到工具信息

## 9. 技术实现要点

### 9.1 标签状态管理

- 使用 Zustand 创建工作区 Store
- Store 管理标签列表和活跃标签
- 通过 `display: none` 保持组件挂载

### 9.2 工具路由适配

现有工具组件不需要修改，它们仍然是独立的 React 组件。工作区只是改变了它们的渲染方式（从路由切换变为标签切换）。

### 9.3 侧边栏折叠

- 折叠状态存储在 localStorage
- 折叠时只显示图标或完全隐藏
- 展开时显示完整工具列表

### 9.4 性能考虑

- 每个标签保持挂载会消耗内存
- 对于资源密集型工具，内部实现懒加载
- 后续可考虑 LRU 缓存策略
