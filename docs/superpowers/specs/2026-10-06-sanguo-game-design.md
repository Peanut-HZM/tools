# 设计文档：游戏中心三国杀手游（小程序 · 多人联机身份局）

- 日期：2026-10-06
- 状态：范围已按用户目标收敛（开发+完整验收），参考狼人杀交付流程执行
- 范围：`mini-program/`（package-game 新增 sanguo 页面）+ `backend/`（sanguo 服务端）

## 1. 目标与范围收敛

完整三国杀规则集极大（军争/界/国战/全武将）。V1 收敛为**标准版 4 人身份局**，保证"规则真实、完整可玩、可验收"：

- **身份局 4 人**：1 主公（+1 体力上限）、1 忠臣、1 反贼、1 内奸。身份随机分配（主公亮明，其余暗置）。
- **胜负**（对齐官方）：
  - 主公/忠臣胜：反贼与内奸全部死亡
  - 反贼胜：主公死亡
  - 内奸胜：反贼全灭后亲手杀死主公，成为唯一存活者
- **奖惩**：杀死反贼摸 3 张；主公杀死忠臣弃掉全部牌（手牌+装备）；杀内奸无奖惩
- **武将 8 名（标准版）**：刘备/关羽/张飞/赵云/曹操/吕布/貂蝉/华佗（技能见 §3）
- **牌堆 105 张**（标准 108 去掉 2 张借刀杀人 + 1 张寒冰剑，避开借刀复杂响应链）：
  - 基本：杀×30、闪×15、桃×8
  - 锦囊：决斗×3、过河拆桥×6、顺手牵羊×5、无懈可击×4、南蛮入侵×3、万箭齐发×1、桃园结义×1、五谷丰登×2、无中生有×4、乐不思蜀×3、闪电×2
  - 装备：武器（诸葛连弩/青釭剑/贯石斧/青龙偃月刀）、防具（八卦阵×2、仁王盾）、+1 马×3、-1 马×3
- **明确不做（V1 Non-Goals）**：借刀杀人、主公技（激将/护驾）、判定类武将（司马懿/郭嘉）、火杀雷杀酒、多目标杀（方天画戟）、翻面/铁索连环、语音

## 2. 架构（复用狼人杀验证过的模式）

```
小程序 package-game/pages/sanguo/*        后端 app/services/sanguo/*
  大厅(建房/加入)        HTTP/JWT   →  routes/sanguo.py（prefix /api/games/sanguo）
  对局页(手牌/装备/目标)  WS 个人视角  →  sanguo/manager.py（内存房间+连接+托管心跳）
  记录页(回放)                       →  sanguo/engine.py（服务端权威状态机）
                                     sanguo/cards.py / heroes.py（牌堆/武将）
                                     record.py / records_query.py（结算+过程入库）
```

- 服务端权威：手牌、牌堆、判定均存服务端；WS 推送"公共事件 + 个人视角（手牌/可执行动作）"
- 引擎交互模型：**待响应请求队列**（use/play 需要 target 询问、闪/杀/桃响应、无懈响应）——玩家在"被请求"时提交 response，其余时间在自己出牌阶段自由 use
- 断线托管：超时自动"可执行动作里选第一个合法项/弃牌"；结算与过程入库复用狼人杀模式（timeline JSON + records API）
- 房间：6 位房号、满员 4 人开局、房主可开始/解散、断线 60s 保留托管、闲置回收

## 3. 规则规范（对齐互联网资料）

### 3.1 回合流程（官方六阶段）
准备 → 判定（判定区延时锦囊后置先判：闪电黑桃2-9 受 3 雷伤；乐不思蜀非红桃跳过出牌阶段）→ 摸牌（2 张）→ 出牌（杀每阶段限 1，连弩除外）→ 弃牌（手牌上限=当前体力）→ 结束。从主公起逆时针轮流。

### 3.2 距离与攻击范围
4 人环形座位顺/逆取短：相邻 1、对角 2。-1 马：计算与其他角色距离 -1；+1 马：他人计算与你 +1。杀/顺手牵羊需 距离 ≤ 攻击范围（默认 1；青龙偃月刀 3、贯石斧 2、青釭剑/连弩 1）。

### 3.3 牌效果
- 杀：指定范围内 1 名角色，其出 1 闪否则受 1 伤害；吕布无双→需两闪
- 闪：仅响应；桃：仅濒死/自己出牌阶段回 1（满血不可用）
- 决斗：目标轮流打出杀（从目标开始），不出者受 1 伤害；吕布为攻方时对手需两杀
- 过河拆桥：弃置一名距离 1 内角色的一张牌（手牌随机/装备/判定区）；顺手牵羊：距离 1 内拿一张牌
- 无中生有：摸 2；五谷丰登：每人从亮出的牌各选 1；桃园结义：所有存活角色回 1
- 南蛮入侵：其他角色依次打出杀否则受 1 伤害；万箭齐发：依次打出闪否则受 1 伤害
- 无懈可击：响应锦囊生效（对单目标锦囊/群体锦囊的单个目标），任意存活角色可出，不递归
- 乐不思蜀：置目标判定区；闪电：置自己判定区，判定黑桃 2-9 受 3 雷伤否则移给下家
- 装备：武器（攻击范围：连弩 1+杀无限、青釭 1+无视防具、贯石斧 2、青龙刀 3）；八卦阵（需闪时判定红色视为闪）；仁王盾（黑色杀无效）；±马（距离修饰）

### 3.4 濒死
体力降至 0：从当前回合角色起按座位顺序询问所有人出桃（华佗：回合外红色牌当桃）；无人出则死亡。求桃响应也走待响应队列。

### 3.5 武将技能（8 名，1-2 技能）
| 武将 | 势力 | 体力 | 技能 |
|---|---|---|---|
| 刘备 | 蜀 | 4 | 仁德：出牌阶段可将任意张手牌交给其他角色，累计给出≥2 张回 1 体力（每阶段限一次回复） |
| 关羽 | 蜀 | 4 | 武圣：红色手牌可当杀使用或打出 |
| 张飞 | 蜀 | 4 | 咆哮：锁定，出牌阶段使用杀无次数限制 |
| 赵云 | 蜀 | 4 | 龙胆：杀可当闪、闪可当杀使用或打出 |
| 曹操 | 魏 | 4 | 奸雄：受到伤害后可获得造成伤害的牌 |
| 吕布 | 群 | 4 | 无双：锁定，你使用杀时目标需两张闪；你决斗时对手需两张杀 |
| 貂蝉 | 群 | 3 | 离间：出牌阶段限一次，弃一张牌令两名男性角色决斗；闭月：结束阶段摸一张牌 |
| 华佗 | 群 | 3 | 急救：回合外红色牌可当桃；青囊：出牌阶段限一次，弃一张手牌令一名已受伤角色回 1 |

主公为任意武将 +1 体力上限。主公技 V1 不做（Non-Goals）。

## 4. 静态资源
- 武将头像/卡牌面：与狼人杀同策略——官方图有版权，采用**程序绘制统一风格**（势力色底+武将名/牌名+花色），压入分包
- 分包体积预算 ≤1.5MB

## 5. 验收计划
1. 规则一致性：六阶段/距离/每条牌效果/8 技能/濒死/奖惩/胜负（逐条 → pytest）
2. 压测：随机对局（全部武将组合）多局无死锁终局
3. API 全场景：建房/加入/开始/行动/响应/错误路径/权限
4. **多 agent 角色扮演**：4 个 agent 分别扮演主公/忠臣/反贼/内奸，经真实后端打完整局，过程入库
5. UI：大厅/对局页（手牌/装备/目标选择/响应）/记录页回放，浏览器截图
6. 落库验证：结算+timeline 可通过 records API 回看
