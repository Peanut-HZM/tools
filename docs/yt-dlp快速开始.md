# yt-dlp 服务器下载 - 快速开始

## 🚀 立即使用

### 1. 访问应用
打开浏览器访问: **http://localhost:3000**

### 2. 进入视频下载器
点击首页的 **"网页视频下载"** 工具卡片

### 3. 开始下载

#### 方式1: 下载YouTube视频
```
1. 输入YouTube视频URL
   例如: https://www.youtube.com/watch?v=jNQXAC9IVRw

2. 点击 "提取视频" 按钮

3. 在视频列表顶部选择质量
   推荐: 720p (平衡质量和大小)

4. 点击视频卡片上的 "服务器下载" 按钮

5. 等待进度条完成（会显示速度和剩余时间）

6. 文件自动下载到浏览器的下载文件夹
```

#### 方式2: 下载HLS流媒体视频
```
1. 输入包含HLS视频的网页URL

2. 点击 "提取视频" 按钮

3. 找到标记为 "HLS流媒体" 的视频（红色标签）

4. 选择质量（推荐: 最佳质量）

5. 点击 "服务器下载 (支持HLS)" 按钮

6. 等待下载完成

7. 获得完整的MP4文件
```

#### 方式3: 下载普通视频
```
1. 输入网页URL

2. 点击 "提取视频" 按钮

3. 找到MP4/WebM视频

4. 可以选择:
   - "直接下载" (快速)
   - "服务器下载" (更可靠)

5. 文件自动下载
```

## 📊 质量选择指南

| 质量 | 分辨率 | 文件大小 | 适用场景 |
|------|--------|---------|---------|
| 最佳质量 | 最高可用 | 最大 | 收藏、高质量播放 |
| 1080p | 1920x1080 | 大 | 电脑播放 |
| 720p | 1280x720 | 中等 | **推荐** - 平衡质量和大小 |
| 480p | 854x480 | 较小 | 手机播放 |
| 360p | 640x360 | 小 | 快速下载、网络慢 |
| 最低质量 | 最低可用 | 最小 | 测试、预览 |

## 💡 使用技巧

### 1. 快速测试
- 第一次使用建议选择 "最低质量" 或 "360p"
- 下载速度快，可以快速验证功能

### 2. 日常使用
- 推荐选择 "720p"
- 质量好，文件大小适中

### 3. 收藏保存
- 选择 "最佳质量" 或 "1080p"
- 获得最高质量的视频

### 4. 网络慢时
- 选择 "480p" 或 "360p"
- 下载速度更快

### 5. 多个视频
- 可以同时下载最多5个视频
- 其他视频会自动排队

### 6. 取消下载
- 下载中可以点击 "取消" 按钮
- 立即停止下载

## ⚠️ 注意事项

### 限制
1. **文件大小**: 最大500MB
2. **并发数量**: 最多5个同时下载
3. **任务过期**: 1小时后自动清理

### 建议
1. **版权**: 仅下载有权使用的内容
2. **网络**: 确保网络连接稳定
3. **空间**: 确保有足够的磁盘空间
4. **质量**: 根据需求选择合适的质量

### 常见问题

#### Q: 下载速度慢？
A: 
- 选择较低质量（360p或480p）
- 检查网络连接
- 视频源服务器可能限速

#### Q: 下载失败？
A:
- 检查URL是否正确
- 尝试选择不同质量
- 某些视频可能需要登录
- 某些视频有地区限制

#### Q: 找不到视频？
A:
- 某些视频是动态加载的
- 尝试使用浏览器开发者工具（F12）
- 查看网络请求中的视频URL

#### Q: 可以下载多少个视频？
A:
- 同时最多5个
- 总数量没有限制
- 任务会自动排队
