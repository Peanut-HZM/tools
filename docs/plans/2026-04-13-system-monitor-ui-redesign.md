# 系统性能监控页面 UI 美化设计

**目标**: 将系统性能监控页面改造为紧凑高密度布局，节省 30-40% 垂直空间，增强视觉层次

**架构**: 纯前端改造，只修改 `SystemMonitor.tsx`，不涉及后端

**设计原则**: Bento Grid 紧凑风格 + 深色主题层次化

---

## 改造清单

### 1. 整体布局
- 页面背景 `bg-slate-950`，卡片 `bg-slate-900`
- 卡片圆角 `rounded-xl`，间距 `gap-3`
- 标题文字 `text-white`，次要文字 `text-slate-500`

### 2. 系统信息卡片
- 从 3列 grid 改为 flex-wrap 标签行
- 用 `|` 分隔符，3 行展示 8 个字段
- 节省约 60% 垂直空间

### 3. 资源卡片
- 内边距 `p-4` → `p-3`
- 百分比数字 `text-3xl` → `text-2xl`
- Sparkline 加粗到 2px，`opacity-80`，高度 32px
- Sparkline 增加渐变填充
- `<details>` 默认折叠

### 4. 进程表格
- 行高 `px-3 py-2` → `px-2 py-1.5`
- 字体 `text-sm` → `text-xs`
- 终止按钮 hover 显示在进程名右侧
- 分页区域紧凑化

### 5. 工具栏
- 更新时间与间隔选择器视觉合并
- 自动刷新 + 手动刷新合并为一个 Toggle

### 6. 视觉层次
- 进度条增加 glow 效果
- 高占用进程数字更醒目的红色
