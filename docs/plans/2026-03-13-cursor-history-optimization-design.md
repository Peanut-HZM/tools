# Cursor 对话历史工具优化设计文档

**创建日期**: 2026-03-13
**作者**: AI Assistant
**状态**: 已批准

---

## 1. 背景与目标

### 1.1 现状分析

当前 Cursor 对话历史工具已具备基础功能：
- 三栏布局（项目列表、会话列表、消息内容）
- 项目/会话搜索
- 全局搜索
- 分页加载（滚动加载更多）
- 自定义 Cursor 数据路径
- Markdown 渲染

### 1.2 存在问题

1. **用户体验**：缺少消息复制、导出、收藏等基础操作
2. **功能单一**：缺乏统计分析、标签管理等增强功能
3. **性能瓶颈**：大量消息时加载缓慢，无缓存机制
4. **智能化不足**：缺少 AI 辅助分析、摘要等功能

### 1.3 优化目标

- 提升用户体验，增加常用操作功能
- 增强数据分析能力，提供可视化统计
- 优化性能，支持大规模数据浏览
- 引入 AI 能力，提供智能摘要和分析

## 2. 技术方案

### 2.1 用户体验优化（A）

#### 2.1.1 视觉设计改进

| 功能 | 描述 | 实现方式 |
|------|------|----------|
| 主题切换 | 3 种预设主题（深空紫、海洋蓝、森林绿） | CSS 变量 + localStorage |
| 消息气泡优化 | 改进对话气泡样式，增加视觉区分 | Tailwind CSS 样式重构 |
| 代码块增强 | 添加一键复制按钮、语言类型图标 | react-syntax-highlighter |
| 布局优化 | 可调节侧边栏宽度，支持全屏模式 | resizable 组件 + 全屏 API |

#### 2.1.2 消息操作功能

| 功能 | 描述 | 实现方式 |
|------|------|----------|
| 复制消息 | 支持复制纯文本或 Markdown | navigator.clipboard API |
| 引用回复 | 引用某条消息进行上下文关联 | 消息 ID 关联 + 高亮显示 |
| 标记重要 | 收藏重要对话到收藏夹 | 后端收藏表 + 星标图标 |
| 添加笔记 | 为消息添加个人备注 | 后端笔记表 + 编辑弹窗 |

#### 2.1.3 导航优化

| 功能 | 描述 | 实现方式 |
|------|------|----------|
| 快速跳转 | 跳转到第一条/最后一条消息 | 滚动定位 API |
| 消息定位 | 搜索结果高亮并定位 | scrollIntoView API |
| 最近访问 | 记录最近 10 个访问会话 | localStorage |
| 面包屑导航 | 显示当前路径 | 路由状态管理 |

### 2.2 功能增强（B）

#### 2.2.1 对话统计面板

| 统计项 | 描述 | 可视化方式 |
|--------|------|------------|
| 概览数据 | 总会话数、总消息数、今日对话数 | 数字卡片 |
| 趋势图表 | 近 7 天/30 天对话数量趋势 | 折线图（recharts） |
| 项目分布 | 各项目的对话占比 | 饼图（recharts） |
| 活跃时段 | 一天中活跃时段热力图 | 热力图 |

#### 2.2.2 导出功能

| 导出格式 | 描述 | 实现方式 |
|----------|------|----------|
| Markdown | 导出为.md 文件，保留格式 | 字符串拼接 + Blob 下载 |
| PDF | 导出为 PDF 文档 | html2pdf.js |
| HTML | 导出为静态 HTML 页面 | 模板渲染 |
| JSON | 导出原始 JSON 数据 | JSON.stringify |

**导出范围选项**：
- 单个消息
- 整个会话
- 批量导出多个会话

**自定义选项**：
- 是否包含代码块
- 是否包含时间戳
- 是否包含头像

#### 2.2.3 标签与分类

| 功能 | 描述 | 实现方式 |
|------|------|----------|
| 会话标签 | 为会话添加自定义标签 | 后端标签表关联 |
| 标签筛选 | 按标签筛选会话 | URL 参数 + 后端过滤 |
| 智能标签 | 基于内容自动推荐标签 | 后端 AI 分析 |

**预设标签**：
- Bug 修复
- 功能设计
- 代码生成
- 概念解释
- 性能优化
- 其他

#### 2.2.4 批量操作

| 功能 | 描述 | 实现方式 |
|------|------|----------|
| 多选模式 | 选择多个会话 | Checkbox + 选中状态 |
| 批量导出 | 导出选中的会话 | 批量 API 调用 |
| 批量删除 | 删除选中的会话 | 批量 API + 二次确认 |
| 批量标记 | 批量添加/移除标签 | 批量 API 调用 |

### 2.3 性能优化（C）

#### 2.3.1 数据加载优化

| 优化项 | 描述 | 实现方式 |
|--------|------|----------|
| 虚拟滚动 | 只渲染可见区域消息 | react-window 库 |
| 图片懒加载 | 消息中的图片延迟加载 | IntersectionObserver |
| 分页优化 | 点击加载代替滚动加载 | 分页按钮 + 无限滚动开关 |

#### 2.3.2 搜索性能

| 优化项 | 描述 | 实现方式 |
|--------|------|----------|
| 本地索引 | 建立本地搜索引擎 | FlexSearch 库 |
| 搜索建议 | 显示热门搜索建议 | 后端热门推荐 |
| 搜索历史 | 记录最近搜索关键词 | localStorage |

#### 2.3.3 缓存机制

| 缓存类型 | 描述 | 实现方式 |
|----------|------|----------|
| 会话缓存 | 访问过的会话本地缓存 | IndexedDB |
| 图片缓存 | 浏览器缓存策略 | Cache-Control 头 |
| 增量更新 | 只加载新增对话数据 | 时间戳对比 + diff |

## 3. 数据模型设计

### 3.1 新增数据库表

```sql
-- 用户收藏表
CREATE TABLE cursor_favorites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id VARCHAR(255) NOT NULL,
    composer_id VARCHAR(255) NOT NULL,
    message_id VARCHAR(255),
    note TEXT,
    tags TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 用户标签表
CREATE TABLE cursor_tags (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id VARCHAR(255) NOT NULL,
    composer_id VARCHAR(255) NOT NULL,
    tag_name VARCHAR(50) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 对话摘要表
CREATE TABLE cursor_summaries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    composer_id VARCHAR(255) NOT NULL,
    summary TEXT,
    key_points TEXT,
    todo_items TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
